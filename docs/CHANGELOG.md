# Changelog

All notable changes to the "Nyumba254" platform will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]
### Added
- Initial `/docs` folder structure.
- **Mortgage Calculator:** Beta release with partner bank rates.
- **360 Tour Viewer:** Support for Equirectangular projection.

### Changed
- Refactored authentication to use HTTP-Only cookies for refresh tokens.
- Updated landing page copy to focus on "Home Ownership Democratization".

## [1.0.0] - 2025-12-01
### Added
- Core platform launch.
- Property Search module.
- User Dashboard (Buyers/Tenants).
- Agent Dashboard (Listing Management).
- Admin Dashboard (Super Admin).

### Fixed
- Fixed issue where mobile menu would not close on route change.
- Resolved latency issues with image uploads in S3.
